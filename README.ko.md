# 과태료 감경시계 (Fine Discount Clock) — 과태료·범칙금 감경 기한을 놓치지 마세요

과태료와 범칙금은 대개 조기 납부 감경 기한이 붙어 있는데, 고지서를 확인할 무렵에는 이미 기한이 지나 있는 경우가 많습니다. 이 앱에서는 고지서를 하나씩 등록하고, 감경 기한까지 남은 날짜를 확인하며, 감경 금액과 기한을 넘겼을 때의 금액(정액 금액과 가산금 포함)을 비교할 수 있습니다. 과태료·범칙금 고지서를 받은 운전자와, 기한이 닫히기 전에 결정하려는 모든 분을 위해 만들었습니다. 모든 데이터는 기기 안에만 저장되며, 계정 가입도 필요 없습니다.

## 기능

- 📋 **고지서 등록**: 과태료 또는 범칙금 고지서의 이름, 원래 금액, 감경 금액(선택), 수령일, 의견제출 기한, 납부 기한을 기록합니다.
- ⏰ **D-day 카운트다운**: 진행 중인 고지서마다 핵심 기한을 D-n, D-DAY, D+n 형식으로 보여주고, "마감 임박"(D-0~D-3)과 "기한 지남" 배지를 붙입니다.
- 💸 **금액 비교**: 결과 화면에서 감경 납부 금액, 감경 기간이 지난 뒤의 전액, 3% 가산금이 붙은 금액을 나란히 비교합니다.
- 📉 **가산금 일정표**: 과태료는 월별로 3% 가산금과 월 1.2% 중가산금을 최대 60개월까지 표로 보여줍니다. 범칙금은 첫 10일 이후 20%가 오르는 두 단계 납부 일정을 보여줍니다.
- ✅ **결정 기록**: 고지서를 조기 납부, 기한 후 납부, 이의 제기, 미정 중 하나로 표시할 수 있습니다. 홈 화면에는 조기 납부로 아낀 금액이 요약됩니다.
- 🔗 **앱 공유**: 결과 화면에서 토스 공유 시트로 앱을 공유할 수 있으며, 링크를 열면 홈 화면으로 바로 들어갑니다.
- 🗑️ **고지서 삭제**: 결과 화면에서 고지서를 지울 수 있습니다.
- 💾 **기기 내 저장과 복구**: 고지서는 `localStorage`에 저장됩니다. 읽을 수 없는 데이터는 앱을 새로 시작하기 전에 최대 3개까지 백업하고, 더 새로운 앱 버전이 쓴 데이터는 감지해서 건드리지 않습니다. 고지서는 최대 50건까지 보관합니다.
- 🌗 **다크 모드**: 색상은 TDS 컴포넌트와 `--adaptive*` CSS 변수를 사용합니다.

> 계산은 `src/lib/fineRules.ts`에 옮겨 둔 질서위반행위규제법과 도로교통법을 따릅니다. 금액과 기한은 받은 고지서와 대조해 확인하세요.

## 기술 스택

- **프레임워크**: React 18 + TypeScript 5.8, Vite 6으로 빌드 (정적 클라이언트 번들만 사용)
- **라우팅**: React Router 7 (`BrowserRouter`)
- **UI**: `@toss/tds-mobile`과 `@toss/tds-mobile-ait`(Toss Design System), `@emotion/react`와 `@emotion/styled`, 테마는 CSS 변수로 처리
- **플랫폼 SDK**: `@apps-in-toss/web-framework` — 햅틱, 공유, 리뷰 요청, 계측, 리워드·배너 광고에 사용
- **저장소**: 브라우저 `localStorage`. 백엔드, 데이터베이스, 외부 API는 없습니다
- **인증**: 없음. 토스 로그인이나 익명 사용자 키를 사용하지 않습니다
- **테스트**: jsdom과 Testing Library를 쓰는 Vitest, 시각 스모크 테스트는 Playwright(`e2e/`)

## 시작하기

```bash
# 1. 의존성 설치
npm install

# 2. 단위 테스트 실행
npx vitest run

# 3. 프로덕션 번들 (빌드 후 개발용 코드 유출 검사도 함께 실행)
npx vite build

# 4. 토스 번들 생성 후 배포 (앱인토스 API 키 필요)
npx ait build
npx ait deploy --api-key <YOUR_API_KEY>
```

빌드하기 전에 `.env.example`을 `.env`로 복사해 값을 채우세요. Vite는 `VITE_*` 변수를 빌드 시점에 넣으므로, 값을 바꾸면 다시 빌드해야 합니다.

## 환경 변수

| 변수 | 설명 | 필수 여부 |
|---|---|---|
| `VITE_TOSS_AD_SLOT_ID` | 앱인토스 콘솔에서 발급받은 리워드 전면 광고 슬롯 ID입니다. 결과 화면의 가산금 일정표와 타임라인을 여는 관문으로 쓰입니다. 비워 두면 광고 없이 바로 열립니다. | 아니요 |
| `VITE_TOSS_AD_GROUP_ID` | 앱인토스 콘솔에서 발급받은 배너 광고 그룹 ID입니다. 홈과 결과 화면에 표시됩니다. 비워 두면 배너를 그리지 않습니다. | 아니요 |
| `VITE_SHARE_OG_URL` | 공유 링크에 붙는 미리보기 이미지 URL입니다(카카오톡, 문자 미리보기). 비워 두면 미리보기 이미지 없이 링크만 공유됩니다. | 아니요 |

## 배포

1. `.env`에 `VITE_*` 값을 설정합니다. `apps-in-toss.config.ts`의 앱 이름(`fine-discount-clock`)은 앱인토스 콘솔에 등록한 이름과 대소문자까지 정확히 같아야 합니다. 다르면 배포 에러 4031이 납니다.
2. `npx ait build`로 토스 번들을 만듭니다.
3. `npx ait deploy --api-key <YOUR_API_KEY>`로 번들을 올리거나, 앱인토스 개발자 콘솔에서 직접 업로드합니다.
4. 개발자 콘솔에서 심사를 신청합니다. 신청 전에 다음을 확인하세요.
   - 테스트용 광고 슬롯, 광고 그룹, 프로모션 코드가 하드코딩되어 있지 않습니다. 모든 ID는 `.env`에서 가져옵니다.
   - 프로덕션에서 `console.error` 출력이 없습니다.
   - 외부 이동이 없고, 상단 뒤로가기나 닫기 버튼을 직접 만들지 않았습니다. 두 기능은 토스 내비게이션 바가 처리합니다.
5. 승인되면 토스에 앱이 노출됩니다. 리뷰와 평점은 앱의 상세 페이지에 표시됩니다.
